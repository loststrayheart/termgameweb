# Richman Shop UI - PUBG Mobile & VALORANT Top-Up Web

เว็บไซต์เติมเกมออนไลน์สไตล์ **Richman Shop** (`richmanshop.com/th-th/home`) ที่คัดสรรเฉพาะ 2 เกมยอดนิยมตามความต้องการ:
1. **PUBG Mobile (ID ไทย)** - เติมผ่าน Player UID
2. **VALORANT (Riot ID)** - เติมผ่าน Riot ID (Name#TAG)

พร้อมระบบ **ล็อกอินด้วย LINE (LINE Login)** เพื่อสะสม Richman Coins และบันทึกประวัติการเติมเงิน

---

## 🌟 ฟีเจอร์เด่นที่ถอดแบบจาก Richman Shop

1. **แถบ FLASH SALE ด้านบนสุด (เหมือนภาพตัวอย่าง 1):**
   - โลโก้ `F⚡ASH SALE` สีแดงสไตล์ Richman Shop
   - ตัวนับเวลาถอยหลังแบบสด (Live Countdown Timer: วัน : ชม. : นาที : วินาที)
   - การ์ดสินค้า Flash Sale ขอบสีทอง-ส้ม พร้อมป้ายลดราคา (เช่น `-18.50%`, `-20%`)
   - หลอดแสดงสถานะสต็อก `🔥 ขายแล้ว 444/499`
   - เมื่อคลิกที่แพ็กเกจ Flash Sale จะพาไปยังหน้าเติมเงินพร้อมเลือกแพ็กเกจให้อัตโนมัติ

2. **แถบ Hero สีเหลืองเอกลักษณ์ (Yellow Banner):**
   - Breadcrumb: `หน้าแรก > เติมเกมผ่าน UID & Riot ID`
   - พาดหัวใหญ่: `เติมเกมราคาถูก PUBG & VALORANT เปิด 24 ชั่วโมง`
   - ช่องค้นหาเกมพร้อมระบบกรองแบบเรียลไทม์
   - 3 เครื่องหมายการันตี:
     - `✓ ไม่ต้องใช้รหัสผ่าน`
     - `✓ ผู้ใช้กว่า 1 ล้านคน`
     - `✓ แอดมินดูแล 24 ชม.`

3. **หน้าสั่งซื้อและขั้นตอนการเติมเงิน (เหมือนภาพตัวอย่าง 2):**
   - **ขั้นตอนที่ 1:** กรอก UID (PUBG เป็นตัวเลข) หรือ Riot ID (VALORANT เป็น Name#TAG) พร้อมปุ่ม **"ตรวจสอบชื่อในเกม"** จำลองการดึงชื่อตัวละครจริง และตัวเลือกจำบันทึก ID
   - **ขั้นตอนที่ 2:** ช่องทางชำระเงินครบทุกแบบตามหน้าเว็บ:
     - สแกนผ่านพร้อมเพย์ (QR PromptPay) - ไม่มีค่าธรรมเนียม
     - QR PromptPay ธนาคาร - ค่าธรรมเนียม 5%
     - ชำระผ่านบัตรเครดิต (Visa/Mastercard)
     - ผ่อนชำระผ่านบัตรเครดิต 0% สูงสุด 10 เดือน
     - True Money Wallet
     - True Money Pay Next (ใช้ก่อน จ่ายทีหลัง)
     - True Money PromptPay (Scan)
     - ShopeePay (SPayLater)
     - LINE Pay
   - **ขั้นตอนที่ 3:** เลือกแพ็กเกจ UC (PUBG) หรือ VP (VALORANT) พร้อมแสดงส่วนลด โบนัสแต้ม และราคา
   - **ขั้นตอนที่ 4:** สรุปคำสั่งซื้อ แถบลอยด้านล่างพร้อมยอดชำระสุทธิ และปุ่มยืนยันคำสั่งซื้อ

4. **ระบบ LINE Login (ล็อกอินด้วย LINE):**
   - ปุ่มสีเขียวอย่างเป็นทางการ `#06C755`
   - Modal เข้าสู่ระบบรองรับทั้ง Quick 1-Click Login, สแกน LINE QR Code หรือระบุชื่อบัญชี
   - เมื่อล็อกอินแล้ว จะแสดง Avatar, ชื่อบัญชี LINE, ป้าย Verified และยอดสะสม **Richman Coins**
   - เมนูดรอปดาวน์ดูประวัติคำสั่งซื้อและออกจากระบบ
   - ข้อมูลผู้ใช้และประวัติออเดอร์ถูกบันทึกลง `localStorage`

5. **ระบบจำลองการชำระเงิน (Payment Simulation):**
   - แสดงหน้าสแกน Thai QR Payment พร้อมตัวเลขอ้างอิงและเวลานับถอยหลัง 15 นาที
   - ปุ่มจำลองชำระเงินสำเร็จ เพื่อทดสอบ Flow จนได้รับใบเสร็จและแต้มเข้าไอดีจริง
   - บันทึกคำสั่งซื้อลงหน้า "ประวัติคำสั่งซื้อ" อัตโนมัติ

6. **ปุ่มลอยติดต่อ (Floating Widgets):**
   - ป้าย "เติมเกมเสร็จอย่าลืมกดรับสิทธิ์! หมุนวงล้อลุ้น UC & VP ฟรี"
   - ปุ่มสีเขียว "ติดตาม Pro LINE แอดมินดูแล 24 ชม."

## 🚀 วิธีการรันโปรเจกต์

```bash
# 1. ติดตั้ง Dependencies
npm install

# 2. เริ่มต้น Dev Server
npm run dev

# หรือเข้าชมผ่าน URL ที่เปิดอยู่:
# http://localhost:5173
```

## 🛠️ Tech Stack
- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4 + Prompt / Kanit Google Font
- **Database:** Supabase (PostgreSQL Cloud)
- **Deployment:** Vercel (Production CI/CD)
